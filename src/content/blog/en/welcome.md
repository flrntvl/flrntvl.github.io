After a few false starts, this blog finally exists. Nothing dramatic yet — a static site, a dark theme, a terminal that types itself — but the scaffolding is there, and that's what matters: I can write now without rebuilding anything first.

## What to expect here

No editorial calendar, no publishing schedule. I'll write when something feels worth noting: a library that surprised me, a bug that took longer to understand than it should have, an architecture decision I'd make differently today. Right now that's mostly Ruby and agentic coding taking up my evenings — the first few posts will probably be about those.

Nothing here is set in stone: I'm still learning Astro, so nothing here is perfect — but that's fine, I'm shipping it anyway. The format will likely evolve along with the rest of the site, which is, for now, still very much a work in progress.
