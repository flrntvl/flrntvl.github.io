# flrntvl.dev — SEO guidelines

> Binding, like [DESIGN.md](DESIGN.md): read before creating or modifying any page or layout. The rules below are implemented in `src/layouts/Base.astro` — do not bypass them with hand-written meta tags.

## 1. What `Base.astro` emits for every page

- **Canonical link** (`<link rel="canonical">`) built from the page path + `Astro.site`.
- **hreflang trio**: self reference, the other language, and `x-default` (see §3).
- **RSS discovery**: `<link rel="alternate" type="application/rss+xml">` pointing at the current locale's feed.
- **Open Graph / Twitter tags**: title, description, image (`AVATAR_URL` until a dedicated og-image exists), `twitter:card`.
- **noindex mode**: when the `noindex` prop is set (404), canonical, description, OG and hreflang are all omitted — never indexable content on those pages.

Props a page may set: `title`, `description`, `langHref`, `alternateHref`, `publishedTime`, `image`, `noindex`.

## 2. Expected props per page type

| Page             | `title`                   | `description`  | `publishedTime` | `alternateHref`          |
| ---------------- | ------------------------- | -------------- | --------------- | ------------------------ |
| Home / blog list | locale default via LABELS | locale default | —               | other locale root (auto) |
| Article          | `${title} — flrntvl.dev`  | standfirst     | required        | `translationHrefExact()` |
| 404              | —                         | —              | —               | — (`noindex`)            |

## 3. hreflang rules

- Every indexable page declares itself (`hreflang={lang}`), its translation (`hreflang={otherLang}`) and an `x-default` pointing at the **French** version.
- For articles, pass `alternateHref={await translationHrefExact(entry, target)}` — **never** `translationHref()`, whose home-page fallback would advertise the home page as the translation of an article.
- The two helpers are not interchangeable: `translationHref()` (home-page fallback) is for UI navigation such as the header's language switcher, where sending the visitor somewhere is better than nowhere; `translationHrefExact()` (null) is for anything a crawler reads.
- `alternateHref` semantics: omitting the prop means "use the other locale's root"; passing explicit `null` means "no translation exists, emit nothing".

## 4. Articles

- Pass `published` as `publishedTime`: this switches `og:type` to `article` and adds `article:published_time`.
- `ArticleContent.astro` injects JSON-LD `BlogPosting` through the `<slot name="head" />` of Base: headline, description (standfirst), dates, author, `inLanguage`. `dateModified` falls back to the publish date. Keep the script tagged `is:inline`.

## 5. Feeds & crawlers

- RSS: `/rss.xml` (fr) and `/en/rss.xml` (en), generated by `src/lib/rss-feed.ts`. Items use the frontmatter `standfirst` as description; channel title/description come from `LABELS[lang].meta`. A new locale needs a matching endpoint under its page folder.
- Sitemap: generated automatically by `@astrojs/sitemap`, referenced both from `<head>` and `public/robots.txt`.
- `public/robots.txt` points crawlers at `https://flrntvl.dev/sitemap-index.xml` — update it if the domain ever changes.

## 6. Checklist before deploying SEO-relevant changes

1. `make check` green.
2. Build, then inspect the rendered `<head>` of one page per type (home fr/en, article fr/en, 404).
3. hreflang pairs resolve to real URLs, in both directions.
4. Validate JSON-LD and OG tags with an external checker (Rich Results Test, metatags.io…).
